# 拾光校园——校园失物招领 WEB 应用

本项目基于第一次结对作业的墨刀原型实现，完成“发布信息—浏览或搜索—查看详情—联系发布者—更新状态”的完整闭环。使用原生 HTML、CSS、JavaScript，无需安装框架或启动服务器。

## 一、运行方法

1. 下载并解压项目；
2. 使用 Google Chrome 打开项目根目录中的 `index.html`；
3. 从首页开始浏览，也可以使用底部导航进入搜索、发布和“我的发布”；
4. 如需重新体验初始数据，点击右上角“↻”，确认后即可恢复示例数据。

项目使用浏览器 `localStorage` 保存新发布的信息和状态，刷新页面后数据仍会保留。

## 三、核心功能

- 首页集中浏览寻物与招领信息，并按类型筛选；
- 按物品名称、描述、分类和地点搜索；
- 发布寻物或招领信息，进行必填项和联系方式校验；
- 查看物品详情、当前状态与发布者联系方式；
- 一键复制联系方式；
- 在“我的发布”中标记“已找到”或“已归还”，并同步到首页与详情页；
- 对搜索无结果、表单信息不完整、详情不存在等情况给出明确提示；
- 数据本地保存与一键恢复示例数据。

## 四、运行单元测试

安装 Node.js 18 或更高版本后，在项目根目录执行：

```bash
npm test
```

测试使用 Node.js 内置的 `node:test` 与 `assert`，无需安装第三方依赖。当前共 16 个测试用例，覆盖搜索、组合筛选、表单校验、信息创建、状态切换与分类去重。

## 五、浏览器与兼容性

按作业要求，开发和测试统一使用 Google Chrome。页面为响应式布局，在电脑和手机宽度下均可正常显示。若浏览器限制剪贴板权限，程序会自动使用兼容方式复制联系方式。

## 六、数据与隐私说明

本项目是课程演示作品，不连接服务器。所有数据仅保存在当前浏览器中；示例联系方式均为测试数据，请勿用于真实联系。
